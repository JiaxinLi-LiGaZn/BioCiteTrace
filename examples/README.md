# Synthetic example

The files in this directory describe a fictional target method, a fictional citing study, and a short synthetic article created for testing this repository. The example text and metadata are dedicated to the public domain under CC0 1.0.

`example_study_capsule.json` is the deterministic output of the public capsule builder. `example_classification.json` is a hand-authored, schema-valid illustration of a multi-purpose result: the fictional study both applies the method to biological data and extends it. It is not a model-performance claim.

`example_human_scoring.csv` shows the long-format scoring representation. The same study appears once for each non-exclusive category; its machine and human values are synthetic and are provided only to exercise the scoring command.
